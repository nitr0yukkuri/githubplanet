# 初回ホームの起動

初訪問のホームと展示モードでは、説明を読む間のThree.jsとGPU初期化を利用開始の操作まで待ちます。案内中は既存の星空画像を縮小した背景を使い、OKを押すと既存のホームを起動します。再訪・ショーケース・デモはすぐに起動します。

案内用ロゴは元のPNGを表示サイズに合わせたWebPへ縮小します。元の画像や3D描画のテクスチャは変更しません。生成コマンドは`node scripts/generate-home-preview-assets.mjs`です。Chromeと開発依存が必要です。

## 検証

```sh
npm test
node scripts/audit-home-startup.mjs
```

ブラウザー監査はDBなしの使い捨てローカルサーバーを使います。初訪問の説明中は3Dモジュールを読み込まず、1回のOKで起動すること、展示・再訪・ショーケースの起動、390px画面で案内が収まることを確認します。画面記録はGit管理外の`artifacts/home-startup/`へ保存します。
